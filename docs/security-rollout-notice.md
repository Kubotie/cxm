# 利用者向け周知テンプレート（セキュリティ改修 / 全員の再ログインが必要）

そのままコピーして Chatwork / Slack / メールに貼れる文面。
**パスワードそのものはここに書かない。** 1Password か口頭で別途渡すこと。

## A. 事前告知（デプロイの 1〜2 日前）

```
【CXM / Ptengine AI パイプライン】セキュリティ改修のお知らせ（◯月◯日 実施予定）

いつもお使いいただきありがとうございます。CXM の認証まわりを改修します。

■ いつ
　◯月◯日（◯）◯◯:◯◯ ごろ

■ みなさんに影響すること（2 つだけです）

　1. 全員が一度ログアウトされます
　　 作業中の画面を開いたままでも、次の操作で ログイン画面に戻ります。
　　 入力中の内容が失われる可能性があるので、当日は区切りのよいところで保存をお願いします。

　2. 共有パスワードが変わります
　　 新しいパスワードは 1Password（項目名：CXM 共有パスワード）に入れておきます。
　　 ※ すでに「自分専用のパスワード」を設定している方は、これまでどおりそのままお使いいただけます。

■ お願い（任意ですが推奨）
　ログインし直したあと、CXM の [設定] から自分専用のパスワードを設定してください。
　共有パスワードは移行期間の暫定措置で、全員の設定が終わり次第廃止します。

■ 何が変わるのか（気になる方向け）
　ログイン状態の持ち方を、改ざんできない署名つきの方式に切り替えます。
　あわせて、ログインしていない人が API から社内データを読めてしまう状態を塞ぎます。
　画面の見た目や操作は変わりません。

不明点は 窪田 までお願いします。
```

## B. 実施直後

```
【CXM / Ptengine AI パイプライン】セキュリティ改修 完了

先ほど反映しました。お手数ですが、再度ログインをお願いします。

・ログイン画面 https://cxmx.vercel.app/login
・共有パスワードは新しいものに変わっています（1Password：CXM 共有パスワード）
・自分専用のパスワードを設定済みの方は、これまでどおりのパスワードで入れます

ログインできない場合:
　1. ブラウザを再読み込み（Cmd/Ctrl + Shift + R）
　2. それでも駄目なら、cxmx.vercel.app の Cookie を削除してから再度お試しください
　3. 解消しない場合は 窪田 まで（画面のスクリーンショットがあると助かります）

ログイン後、ぜひ [設定] から自分専用のパスワードを設定してください。
```

## C. 個別パスワード設定の案内（B のあと、数日後のリマインド）

```
【CXM】自分専用のパスワードを設定してください

共有パスワードは暫定措置です。全員の設定が終わったら廃止します。

手順（30 秒）
　1. https://cxmx.vercel.app/v2/settings を開く
　2. 「パスワード」欄で、現在のパスワード（＝共有パスワード）を入力
　3. 新しいパスワード（10 文字以上）を設定

設定後は、共有パスワードでは入れなくなります。
```

## D. 技術メンバー向け（開発者がいる場合）

```
CXM のセキュリティ改修を反映しました。ローカル環境に影響があります。

・.env.local に CXM_SESSION_SECRET が必要です（無いとログインが 503 になります）
　　node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
・APP_PASSWORD も .env.local に必要です（共有パスワード経路を使う場合）
・NEXT_PUBLIC_SUPPORT_BATCH_SECRET は廃止しました。設定していたら削除してください
・Cookie 名が cxm_user_uid → cxm_session に変わりました。旧 Cookie を読むコードは書かないでください
・/api/* は原則すべてセッション必須です。新しい API を足すときは
　　src/lib/auth/guard.ts の requireUser() / requireOpsOrAdmin() などをハンドラ先頭に入れてください

詳細:
　docs/v2-architecture/01-runtime-and-auth.md §5
　docs/security-api-inventory.md
```
